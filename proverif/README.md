# ProVerif for WebAssembly

ProVerif 2.05, the verifier of cryptographic protocols by Bruno Blanchet, Vincent Cheval and Marc Sylvestre, compiled from its source to WebAssembly. It runs in a web browser, on the user's own computer and with no server, under Node, or as a command, and it gives the same output as ProVerif on the command line. Each run has a memory limit, chosen by the page, and can be stopped at any time.

It was made as the verifier of [PieStudio](), a visual editor of ProVerif models, and it is separately published so that anyone can use it: in a course, in another editor, in a page that explains a protocol. Its twin, CryptoVerif for WebAssembly, is in [../cryptoverif/](../cryptoverif/README.md).

**The documentation** is in [../docs/](../docs/index.md), and online at <https://OWNER.github.io/proverif-cryptoverif-wasm/docs/>: [using the engine](../docs/library.md) in a page, in a worker, under Node and as a command; [building it yourself](../docs/building.md), step by step; [how it works](../docs/how-it-works.md); and [the ProVerif manual](../docs/manuals/proverif/index.md).

## What is here

```
dist/                   the engine, ready to copy next to a web page (its .js and .d.ts built from src/)
  ProVerifRunner.js     runs ProVerif from a page; the only script a page needs
  ProVerifEngine.js     runs ProVerif once, in a worker, a page or Node
  proverif-worker.js    the web worker of each run
  proverif.wasm         ProVerif and the OCaml runtime, compiled (2.1 MB, 470 KB compressed)
  proverif.js           the loader of proverif.wasm, generated by Emscripten
  proverif-wasm.js      proverif.wasm as a script, for pages opened from disk
  NOTICE, COPYING, LICENSE-OCaml.txt, LICENSE-Emscripten.txt, VERSION, SHA256SUMS
node/                   the module (index.cjs) and the command (cli.cjs) for Node, compiled from src/node/
src/                    the TypeScript of ProVerifRunner, ProVerifEngine, the worker and node/
tsconfig*.json          the builds of src/: the page and the engine, the worker, Node
build.sh                builds proverif.wasm, proverif.js and proverif-wasm.js from ../upstream/
wasm/                   the C and JavaScript files and the patch that build.sh adds to the sources
example/index.html      a page that verifies a model
tests/                  the checks, and the outputs of native ProVerif on its own examples (expected/)
```

## Try it! It's piece of cake

You can serve the repository with any static web server, and open the example:

```sh
python3 -m http.server 8000      # at the top of the repository, then open http://localhost:8000/proverif/example/
```

The page verifies a small model, or any `.pv` file you open, and lists the results of its queries. Nothing leaves the computer. The page also works when `example/index.html` is opened directly from disk: ProVerif then runs in the page instead of a worker, and the page must wait while it works - this is due to how the file protocol is handled.

## In a web page

```html
<script src="proverif/ProVerifRunner.js"></script>
<script>
  new ProVerifRunner().run(model, {
      fileName: "nspk.pv"
    , maxMemory: 512*1048576
    , onOutput: (channel, text) => console.log(text)
  }).then(result => console.log(result.status, result.exitCode));
</script>
```

[Using the engines](../docs/library.md) has the options of a run, its files and libraries, the worker, the module and the command for Node, and what the licences ask.

## If you have time to waste, build it

Build and test:

```sh
./build.sh

npx tsx tests/check-engine.ts     # 106 examples against native ProVerif, the limit, the worker
npx tsx tests/check-node.ts       # the module and the command for Node
npx tsx tests/check-style.ts      # the conventions of the sources
```

The build is reproducible: with OCaml 5.4.0 and Emscripten 3.1.69 (`sudo apt install build-essential ocaml ocaml-findlib emscripten` on Ubuntu 26.04).
