# CryptoVerif for WebAssembly

CryptoVerif 2.13, the prover of cryptographic protocols in the computational model by Bruno Blanchet and its other authors, compiled from its source to WebAssembly. It runs in a web browser, on the user's own computer and with no server, under Node, or as a command, and it gives the same output as CryptoVerif on the command line, with its default libraries of primitives built in. Each run has a memory limit, chosen by the page, and can be stopped at any time.

It is the twin of ProVerif for WebAssembly ([../proverif/](../proverif/README.md)), built the same way, and the verifier of CryStudio, a visual editor of CryptoVerif models; it is published so that anyone can use it.

**The documentation** is in [../docs/](../docs/index.md), and online at <https://OWNER.github.io/proverif-cryptoverif-wasm/docs/>: [using the engine](../docs/library.md) in a page, in a worker, under Node and as a command, with its interactive mode; [building it yourself](../docs/building.md), step by step; [how it works](../docs/how-it-works.md); and [the CryptoVerif manual](../docs/manuals/cryptoverif/index.md).

## What is here

```
dist/                   the engine, ready to copy next to a web page (its .js and .d.ts built from src/)
  CryptoVerifRunner.js    runs CryptoVerif from a page; the only script a page needs
  CryptoVerifEngine.js    runs CryptoVerif once, in a worker, a page or Node
  cryptoverif-worker.js   the web worker of each run
  cryptoverif.wasm        CryptoVerif, its default libraries and the OCaml runtime (4.0 MB, 0.9 MB compressed)
  cryptoverif.js          the loader of cryptoverif.wasm, generated by Emscripten
  cryptoverif-wasm.js     cryptoverif.wasm as a script, for pages opened from disk
  NOTICE, LICENSE, LICENSE-OCaml.txt, LICENSE-Emscripten.txt, VERSION, SHA256SUMS
node/                   the module (index.cjs) and the command (cli.cjs) for Node, compiled from src/node/
src/                    the TypeScript of CryptoVerifRunner, CryptoVerifEngine, the worker and node/
tsconfig*.json          the builds of src/: the page and the engine, the worker, Node
build.sh                builds cryptoverif.wasm, cryptoverif.js and cryptoverif-wasm.js from ../upstream/
wasm/                   the C and JavaScript files and the patch that build.sh adds to the sources
example/index.html      a page that proves a model
tests/                  the checks, and the outputs of native CryptoVerif on its own examples (expected/)
```

## Try it! It's piece of cake

You can serve the repository with any static web server, and open the example:

```sh
python3 -m http.server 8000      # at the top of the repository, then open http://localhost:8000/cryptoverif/example/
```

The page proves the FDH signature scheme, one of CryptoVerif's examples, or any `.cv` or `.ocv` file you open, and lists the results. The model never leaves the computer. The page also works when `example/index.html` is opened directly from disk: CryptoVerif then runs in the page instead of a worker, and the page must wait while it works - this is due to how the file protocol is handled.

## In a web page

```html
<script src="cryptoverif/CryptoVerifRunner.js"></script>
<script>
  new CryptoVerifRunner().run(model, {
      fileName: "fdh.ocv"
    , maxMemory: 512*1048576
    , onOutput: (channel, text) => console.log(text)
  }).then(result => console.log(result.status, result.exitCode));
</script>
```

[Using the engines](../docs/library.md) has the options of a run, its files and libraries (the default and the post-quantum ones, and `-lib`), the interactive mode, the worker, the module and the command for Node, and what a browser cannot do.

## If you have time to waste, build it

Build and test:

```sh
./build.sh

npx tsx tests/check-engine.ts     # 84 examples against native CryptoVerif, the limit, the interactive mode, the worker
npx tsx tests/check-node.ts       # the module and the command for Node
npx tsx tests/check-style.ts      # the conventions of the sources
```

The build is reproducible: with OCaml 5.4.0 and Emscripten 3.1.69 (`sudo apt install build-essential ocaml ocaml-findlib emscripten` on Ubuntu 26.04).
